# Recommend Skill Evaluation Rubric

- 현재 목표와 입력의 준비 상태를 먼저 판별한다.
- 가장 작은 다음 스킬 하나와 선택 이유를 안내한다.
- 바로 사용할 수 있는 정확한 명시 호출 예시를 제공한다.
- 이미 나온 전문 결과를 쉽게 전달하려는 요청은 도메인 작업을 반복하지 않고 `present-result`로 안내한다.
- 경계가 실제로 모호할 때만 대안 하나나 질문 하나를 추가한다.
- 전문 작업, 파일 변경이나 원격 상태 변경을 직접 수행하지 않는다.
- explicit-only 스킬을 자동으로 호출하거나 수행했다고 표현하지 않는다.
- `review-dev-resume`는 direct-only로 남겨 `recommend-skill`의 추천, 반환값과 호출 예시에서 제외한다.
- direct-only 요청만 주어지면 라우팅 범위 밖임을 알리되 해당 스킬을 이름으로 제안하지 않는다.
